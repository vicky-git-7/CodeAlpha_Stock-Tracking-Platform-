📈 Stock Trading Platform (Java)

A simple console-based Stock Trading Platform built using Java.
This project simulates real-world trading features like buying, selling, portfolio management, and random price updates — all using OOP concepts and Java Collections.

🚀 Features

View live market data

Buy & Sell stocks

Track your portfolio

Check total portfolio value + balance

Random market price updates

Full input validation for safe user interaction

🧰 Technologies Used

Java

OOP (Classes, Objects, Encapsulation)

ArrayList Collection

Scanner input handling

Exception Handling

📁 Project Structure
StockTradingPlatform.java  → Main program  
Stock.java                 → Stock details & price update  
User.java                  → User balance & portfolio access  
Portfolio.java             → Owned stock storage & value calculation  

▶️ How to Run

Clone the repository

Open the project in any Java IDE (VS Code / IntelliJ / Eclipse)

Compile and run:

javac *.java
java StockTradingPlatform
